# 界面规格

基准分辨率 1920×1080。所有尺寸为 CSS 像素。

## 预览页

```
┌──────────────────────────────────────────────────────────────┐
│ 48px 顶栏：文件名 · 格式徽标 · 引擎状态 · 帮助 · 设置 · 关闭 │
├──────────┬───────────────────────────────────┬───────────────┤
│ 240px    │  舞台（#ECEEF1）                  │ 320px 抽屉    │
│ 缩略图栏 │  ┌─────────────────────────────┐  │ 默认收起      │
│          │  │ 幻灯片卡片（12px 圆角）     │  │               │
│          │  └─────────────────────────────┘  │               │
├──────────┴───────────────────────────────────┴───────────────┤
│ 64px 底栏：页码 · 缩放 · 信息 · 从当前页放映 · 开始放映      │
└──────────────────────────────────────────────────────────────┘
```

- 顶栏 `48px`，白底，下边框 `#E5E7EB`，可拖动区域（`-webkit-app-region: drag`）。
- 缩略图栏 `240px`，卡片宽 `200px`、16:9、圆角 `8px`，选中态 `2px #2563EB` 描边。
- 舞台背景 `#ECEEF1`，幻灯片卡片圆角 `12px`，阴影 `0 4px 24px rgba(17,24,39,.08)`。
- 空状态为虚线框，可拖入文件，下方列最近 10 个文件。
- 底栏 `64px`，页码用 `tabular-nums`，缩放步长 10%，「适合窗口」重置为 100%。
- 右侧抽屉 `320px`：格式、容器、页数、页面尺寸、是否加密、引擎路径、转换耗时、缓存操作。

## 放映页

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  ┌────┐                                          ┌────┐      │
│  │ ▲  │              幻灯片（contain）            │ ▲  │      │
│  │1/14│                                          │1/14│      │
│  │ ▼  │                                          │ ▼  │      │
│  └────┘                                          └────┘      │
│                  ┌──────────────────────────┐                │
│                  │ 工具条（浮动、圆角 28px） │  ⏻             │
│                  └──────────────────────────┘                │
└──────────────────────────────────────────────────────────────┘
```

- 背景纯黑，幻灯片 `contain` 等比缩放，阴影 `0 8px 40px rgba(0,0,0,.5)`。
- 左右导航栈距屏幕边缘 `24px`，按钮 `56×56`、圆角 `16px`；页码胶囊 `56×40`、圆角 `12px`。
- 底部工具条距底 `24px`，高 `56px`、圆角 `28px`，`backdrop-filter: blur(18px) saturate(1.4)`；
  工具按钮 `40×40`，分隔线 `1×20`，结束放映按钮 `48×48`。
- 鼠标静止 2.5 秒后所有控件淡出，移动即恢复。
- 幻灯片左上角采样亮度，浅色页面时工具条自动切换为浅色玻璃质感。
- 总览为深色网格覆盖层，每格 `minmax(220px, 1fr)`。

## 交互

| 输入 | 行为 |
| --- | --- |
| 点击画面右侧 1/3 | 下一页 |
| 点击画面左侧 1/3 | 上一页 |
| 双击幻灯片（预览页） | 开始放映 |
| `→ ↓ Space PageDown N` | 下一页 |
| `← ↑ PageUp P` | 上一页 |
| `Home` / `End` | 首页 / 末页 |
| 数字 + `Enter` | 跳到指定页 |
| `B` / `.` | 黑屏 |
| `W` | 白屏 |
| `O` | 总览 |
| `L` | 放大镜 |
| `E` | 橡皮 |
| `?` | 快捷键帮助 |
| `Esc` | 结束放映 |

## 状态

- **转换中**：舞台覆盖半透明层，进度条 `260×4`，文案随阶段变化（识别 / 转换 / 解析）。
- **引擎缺失**：错误卡片给出期望路径、打开日志、重新检测三个出口。
- **缓存命中**：直接进入解析阶段，进度条瞬间走满。
